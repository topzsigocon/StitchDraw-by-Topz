StitchDraw by Topz — VecDraw Integration Phase 3

Adds interactive vector tools to the existing embroidery canvas:
- Select / Move
- Node Edit
- Drag-to-create Rectangle, Ellipse, and Hexagon
- Freehand Pencil
- Delete selected vector object
- Convert selected vector object to Running or Tatami stitch

Vector artwork remains separate from embroidery objects and is retained after conversion.
Changes to vector artwork trigger the existing project autosave path.
No signing key or signing configuration was changed.

After extracting this update at the repository root, run the existing GitHub Actions Android build and tests. Build success is not pre-verified here.
See docs/VEC_DRAW_INTEGRATION_PHASE_3.md for usage and current limitations.
