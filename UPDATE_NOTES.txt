StitchDraw by Topz – VecDraw Integration Phase 5

Included:
- Boolean operations: Union, Subtract, Intersect and Exclude.
- Boolean output is a new editable compound path; source paths are retained.
- Group / Ungroup operations with group-aware canvas selection and movement.
- Safe path cleanup for duplicate and near-collinear line anchors; Bézier handles are preserved.
- UI menu entries and manual QA documentation.

Requirements for Boolean operations:
- Exactly two selected closed PATH objects.
- Both objects must be editable and on the same visible, unlocked vector layer.
- Subtract uses selection order: first selected minus second selected.

Important:
- Boolean output is flattened to editable line nodes at approximately 0.65 mm sampling. Review tight details before stitch conversion or machine export.
- Original vector shapes are not deleted.
- No signing keystore, signing credentials, Gradle configuration, or embroidery engine files are included in this patch.
- Apply this patch over the successful Phase 4 repository state, not over an older repository snapshot.
- Run Android CI before installing the APK.
