StitchDraw by Topz — VecDraw Integration Phase 4

Added:
- Pen / Bézier path construction with drag-created tangent handles and close/finish actions.
- Independent node-anchor and Bézier-handle editing.
- Cusp, Smooth and Symmetric node modes; symmetric-handle state is saved in vector project JSON.
- Insert/delete node, split open paths, and join two selected open paths.
- Multi-select, group move, object alignment and distribution controls.
- Backward-compatible loading of older seven-value node records.

Preserved:
- Existing StitchDraw workspace, embroidery engines, vector-to-stitch pipeline and .STD project container.
- Existing signing configuration and keystore are not part of this patch and must remain untouched in the repository.

Apply this ZIP at the repository root, commit/push, then run Android CI. Local Gradle build could not be completed in this environment because services.gradle.org was unreachable. Treat GitHub Actions as the authoritative compile/test result.
