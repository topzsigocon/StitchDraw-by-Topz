# StitchDraw-by-Topz

## VecDraw integration status

Phase 1 imports the VecDraw vector model, geometry, renderer, SVG importer, tracing, fonts and pattern helpers. Phase 2 connects vector artwork to the existing StitchDraw canvas and `.STD` project lifecycle, with starter shape creation and non-destructive Running/Tatami conversion. See `docs/VEC_DRAW_INTEGRATION_PHASE_2.md` for details and current limits.
